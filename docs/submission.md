## 旅行场景与目标用户

朋友约见面时，每个人的起点、时间和预算都不一样。跨城朋友要协调周末往返；同在上海的朋友，也可能彼此相距几十公里。地图上的几何中点不一定好到达，一份单人最优行程也不一定被全组接受。

中点见面向 2–4 位朋友、异地亲友和小型结伴出行，把每个人的负担放在一起比较。希望先让大家谈成一个都能接受的会合方案，再进入车票与住宿选择。

## 我做了什么

已完成并部署可直接体验的网页：[打开中点见](https://zhongdianjian.super666joey.workers.dev)。

**跨城：让条件参与决策。** 输入各自出发城市、最早出发、最晚回家、往返预算和最长乘车时间。先过滤违反任一人硬条件的组合，再提供三种取舍：

| 方案 | 比较目标 |
|---|---|
| 少一点迁就 | 优先降低全组最大的往返乘车时长，同分时比较总交通费 |
| 少一点花费 | 降低全组往返交通费 |
| 多一点相聚 | 延长所有人共同在目的地的时间窗口 |

支持国内中文城市输入，不再限定长三角；候选城市由用户选择，最多 8 座，首轮建议 1–3 座。支持粘贴文字需求、核对条件、自然语言修改、重算与酒店查询。条件修改后旧方案失效，无解时显示具体冲突。

**同城：用真实路程比较地点。** 搜索并确认每个人的公开地点，选择公交、步行或驾车及个人用时上限；在候选咖啡店等地点间比较每个人的预计路程，优先照顾用时最长者。几何中心只用来寻找候选，最终排名用实际路线计算。

**创新点**是多人约束协商、可解释的公平比较，以及条件变化后可复核的重算。AI 负责理解与工具执行，金额、时间和排名由程序校验。商业探索方向是从朋友约见这一需求，衔接交通与住宿预订；当前已有飞猪预订入口，尚未验证商业转化或收入。

## 百炼使用说明（必填）

- **百炼能力 / 模型：** 阿里云百炼 **Managed Agent**，Qwen3.8-Flash。位于产品运行时核心链路，非仅开发时辅助。
- **调用方式：** 服务端通过百炼 Managed Agent API 创建独立会话、提交任务、审批工具调用并读取执行事件。旅行 Agent 与文字 Agent 分离；网页没有直连模型或本地 FlyAI 自动降级。
- **使用环节与输入输出：** 文字 Agent 将自然语言及当前条件转为待确认的结构化补丁；旅行 Agent 接收已校验的往返车次/酒店查询，执行官方工具；服务端从真实工具输出提取报价并做硬约束筛选。比较结果的数值事实由程序生成，文字 Agent 选择讨论重点。
- **Skill 名称（如有）：** [飞猪官方 FlyAI Skill](https://github.com/alibaba-flyai/flyai-skill)，云端环境安装 `@fly-ai/flyai-cli@1.0.16`，实际使用 `search-train` 与 `search-hotel`。
- **其他工具 / 技术栈：** Next.js、React、TypeScript、Cloudflare Workers / D1；高德 Web 服务提供同城地点与路线。产品插画使用 AI image generation 制作，装饰人物并非真实用户照片。

无需登录即可体验。跨城可用北京、天津→济南作为示例，选择未来可售日期并核对时间限制；同城选择上海，确认徐家汇与五角场地铁站，再查询候选地点并比较。真实跨城查询可能需要数分钟，页面提供等待与错误状态。

本地需要 Node.js 22+：`npm ci` → 复制 `.env.example` 为 `.env.local` → 配置自己的百炼 Managed Agent、FlyAI、高德凭据 → `npm run dev`。访问 `http://127.0.0.1:3088`。不配置凭据也可查看界面并运行离线测试，真实查询不会用假数据兜底。

**当前边界：** 跨城为两天一夜、直达铁路；只比较所选候选城市及本次实际返回车次。共同窗口包含夜间，按车站到离时间计算，未扣市内接驳。住宿报价单独显示；余票未知不当作有票证明。同城仅比较本次候选地点，不宣称全国或全城最优。演示有频率与调用预算上限，达到上限会暂停新查询；不自动下单付款。

## 踩坑记录（可选）

1. **有车次不等于有可用报价。** 匿名返回曾出现 `6x` 脱敏票价和未知余票。适配层逐字段检查，拒绝将它们当作精确价格或库存证明。
2. **云端模型通了，不等于旅行工具通了。** 将真实 Managed Agent 工具事件与查询命令逐一匹配，只接受成功的供应商输出，不能把模型总结当作真实票价。
3. **解释也要可核验。** 真实测试发现模型可能误排费用高低，现由程序生成全部数值事实，Agent 只选择下一步讨论重点。
4. **部署后额度不能随实例重启清零。** Cloudflare D1 原子记录调用预算并加全局查询锁，避免多人体验时重复消耗。
