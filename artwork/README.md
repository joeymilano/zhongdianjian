# 中点见原创美术资源

2026-10-08。使用内置 image_gen 生成，未使用外部素材站，也未调用项目的旅行或百炼 API。

## 文件与用途

| 文件 | 用途 |
|---|---|
| `public/art/meet-town.webp` | 首屏水乡、列车与朋友相聚的微缩场景 |
| `public/art/rail.webp` | 少赶路说明卡、公平方案、真实查询时的等待状态 |
| `public/art/wallet.webp` | 预算说明卡、省钱方案 |
| `public/art/together.webp` | 相聚说明卡、会合示意、停留时间方案 |
| `public/art/travelers.webp` | 四枚通用旅行者头像，用 CSS 位置选择对应头像 |

生产用 WebP 位于 `public/art/`。`prompts.json` 保存每次使用的完整提示词和生成器说明。网页资源均为保留透明度的 WebP；只做尺寸与格式优化，未改变生成内容。界面不引用生成工具临时位置。

共同提示方向：手工微缩 3D、哑光陶瓷与纸黏土、奶油白与暖橙、鼠尾草绿、柔和日光、透明底、无文字和商标。每份完整提示词详见 `prompts.json`。

全部插画属于想象场景，不是住宿实拍、车次证据或实际目的地承诺；人物为装饰头像，不代表真实用户照片。

## 加载与交互

主视觉优先加载；功能插画按需加载并复用缓存，头像共用一张图。所有插画有固定比例，交互图标沿用同一套项目 SVG 并统一颜色与底座。装饰图片不重复朗读；动画遵循系统减少动态效果设置。

## 验证范围

生产构建与类型检查通过；桌面、手机实际浏览器查看透明底、头像裁切、成员增删与城市选择。真实查询已完成，见项目主 README 中的公开演示证据。
